## Mission

Galius Anonymus is the shared home for the tooling, conventions and community around my projects:

- **Build things that run locally first.** Operating systems, games, code tools and AI agents that you can inspect and run on your own machine.
- **Ship with green CI.** Every project is expected to have automated tests, security scanning and reproducible releases.
- **Keep it understandable.** Projects should come with clear docs, honest licenses and a predictable way to report bugs and vulnerabilities.

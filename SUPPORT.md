# Getting help

- **Questions about using a project:** read the project's README and docs first, then open an issue in that project's repository and mark it as a question. If the repository has GitHub Discussions enabled, use those instead.
- **Bugs:** open an issue with the **Bug report** form, including the steps to reproduce, the version and logs (with secrets removed).
- **Feature ideas:** open an issue with the **Feature request** form.
- **Security vulnerabilities:** do **not** open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Code of Conduct concerns:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

These projects are maintained by one person in their spare time. Support is best effort, and there are no guaranteed response times.
